- **No mobile breakpoints.** Headers, toolbars, and Account master-detail are desktop layouts squeezed into phone width; text truncates everywhere. Account Pipeline on mobile is worst — ~60px left rail butchers names into vertical fragments ("Ada Ame Rea Esta"), desktop master-detail shoved onto phone with a huge empty detail pane, search/filter/sort controls clipped to glyphs ("Sor", "Active deal…").
- **No list virtualization/pagination.** Tasks renders ~1000 cards → **151,909px** (mobile) / 93,167px (desktop); Call Queue 5,207px. Filters/controls at top scroll away and never return (must be sticky).
- **Accent color has NO system.** Red (Live pills, alerts, High priority, card borders), blue (avatar, Save, tabs/bars), green (toggles, period pills, "AI Chat"), purple/indigo (FAB, Coaching icon, Draft, Content selection, Today hero gradient), pure black (active "30d" segment, "Open Queue", underlines) all act as "primary" somewhere. Active-selection treatment differs per screen (Coaching solid black segment / Data Quality+Sales Processes black underline / Stage Analytics blue underline).
- **Two card systems:** saturated gradient hero tiles (Today "NEXT BEST ACTION" indigo/purple; Pipeline Overview Confidence blue→purple + Total Pipeline green) — dated ~2019-SaaS, taller so baselines misalign — vs flat white cards everywhere else.
- **Every screen loads content into top ~third, leaves 50-70% dead gray canvas** — product feels unfinished; worst on zero-data screens.
- **Empty/loading states weak and uneven:** Pursuit (great: target icon + headline + one-line + single CTA) > Outbound (okay) > Account Pipeline (wrong ⚠/error-circle icon for a neutral "Select an account" prompt, hollow) > Pipeline Overview (skeleton bars sitting as resting state look broken). Command Center + Call Intelligence captured effectively broken ("Loading…" plain text, blank halves, no shimmer skeletons). Team Dashboard's "Multi-Year Lead Funnel" is the ONE good empty state (clear "Go to Lead Intelligence → Sync All"). Standardize on Pursuit pattern.
- **Priority/urgency saturated to meaninglessness:** everything tagged "High" (red) on Today + Tasks; nearly all real tasks "70-73d overdue" — signal dead.
- **Low-quality AI-extracted content surfaced with no confidence/quality filter:** hundreds of transcript filler fragments as "tasks" ("I'll show you everything," "I'll follow up," "I'll share the deck," "Alyssa can include that in the body"); massive duplication ("Rep will keep Todd posted…" 5+×, "Rep will check with Elena on timing…" ~8 near-identical variants). Duplicate accounts (Avanath appears 4-5× on Today; "Bestcare Treatment Services" twice in Call Queue rows 13&14).
- **Internal engineering text leaking to production UI (professionalism failures):** Call Queue footer "Logging a touch needs the sdr_touches migration (see ledger) — until then the counter holds at the server value"; Coaching leaks raw validation token **"repName required"** as a persistent red banner (while a rep IS selected); Sales Processes shows raw event slugs `intro_booked`/`demo_booked` as blue monospace chips; Settings shows `[Your Name]`/`[Your Company]` template placeholders + example Slack ID `U01234ABCDE` duplicated in helper + placeholder.
- **Floating sparkle FAB overlaps interactive content on nearly every screen** (Deal Intelligence dismiss controls on Today, Call Queue action buttons, Data Validation card edge, detail pane); placement inconsistent (bottom-right most screens, mid-right on Call Queue).
- **Inconsistent heading system:** tiny grey ALL-CAPS labels (YOUR DAY, CALENDAR, PIPELINE FOCUS) vs bold sentence-case titles (Morning Brief, Today's Tasks). Metadata typography tiny low-contrast light gray throughout ("Last updated May 5" — no year, "37d avg in stage") — accessibility/legibility problem.
- **Native OS `<select>` dropdowns** (Account Pipeline: Active deals/All owners/Sort; Outbound: All Verticals/All Status; Content Studio account picker) break the custom-UI illusion — beveled chevrons, system font. Standardize.
- **KPI card component rendered ≥2 ways:** CEO Dashboard faint-gray glyphs top-RIGHT vs Team Dashboard colored-square icons top-LEFT (same component).
- **Every report screen has a DIFFERENT header layout** (back-arrow+subtitle / Modules+Quarter selector / breadcrumb+3 buttons / 4 backfill buttons); no persistent primary nav. **Redundant navigation:** full "All Modules" grid coexists with "Modules" dropdown; All Modules page uniquely lacks the dropdown + role toggle.
- **Number-color semantics inconsistent:** never show alarm-red on zero/empty (Pursuit "0% Avg coverage" red on empty; false alarm). Green means both "pipeline dollars" AND "good" AND "all active" AND (Team Dashboard) late-stage counts colored green implying good when it's a concern.
- **Stage vocabulary + color must be defined once globally:** same stages appear on Account Pipeline badges, Bottleneck funnel+table, Stage Analytics, CEO/Team bars with different names ("Solution Validation" vs "SOL VAL", "Qualifying" vs "QUAL") and different arbitrary rainbow colors, no legend, non-sequential; color hierarchy inverted (largest top-funnel stage rendered gray/disabled).
